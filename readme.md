# git-practice

Git の学習・練習用リポジトリです。

## フォルダ構成

```
git-practice/
├── sql/          # SQL クエリサンプル
├── bat/          # バッチファイルサンプル
└── readme.md     # このファイル
```

## ファイル説明

### sql/sample.sql
- Access DB マスターテーブルの SELECT クエリ
- 医療品目情報の抽出例

### bat/sample.bat
- CSV エクスポート処理のバッチスクリプト
- ログ記録・エラーハンドリングの例

## 用途

- Git コマンドの基本操作練習
- バージョン管理の学習
- コミット・ブランチ・マージの実験場

## 注意

- このリポジトリは練習用です
- 本番データベースへの接続は含まれていません
